# XBOCT Page

Стартовая страница для Chrome, которая организует закладки в перетаскиваемые
группы.

[English version](README.md)

## Возможности

- **Группы закладок в колонках** — раскладывайте ссылки по тематическим группам
  на стартовой странице
- **Drag & drop для всего** — перетаскивайте группы между колонками и закладки
  между группами точно в нужное место
- **Быстрое добавление** — вставьте URL, название и favicon подтянутся
  автоматически
- **Иконки групп** — более 50 иконок для быстрого визуального поиска
- **Тёмная и светлая темы** — переключение одной кнопкой в шапке
- **Импорт и экспорт** — экспорт в JSON, импорт из JSON или HTML-файла закладок
  Chrome
- **Автоматические бэкапы** — один раз выберите файл и получайте мгновенные
  и/или ежедневные копии, плюс синхронизация через Google-аккаунт
- **Поиск** — фильтрация закладок прямо из шапки

## Установка

### Из релиза (рекомендуется)

1. Скачайте свежий `release.zip` со страницы
   [Releases](https://github.com/Ku6epXBOCTuK/XBOCT-page/releases)
2. Распакуйте в постоянное место (расширение загружается из этой папки)
3. Откройте `chrome://extensions` в Chrome
4. Включите **Режим разработчика** (справа вверху)
5. Нажмите **Загрузить распакованное расширение** и выберите распакованную папку
6. Откройте новую вкладку — это ваша новая стартовая страница

### Обновление

Замените содержимое папки файлами из нового релиза и нажмите кнопку обновления
на `chrome://extensions`. Закладки сохранятся.

## Использование

### Управление группами

- **Добавить группу** — кнопка «Добавить группу» внизу любой колонки
- **Переместить группу** — перетащите её за заголовок в любое место любой
  колонки
- **Изменить или удалить группу** — иконка карандаша или меню `⋮` в заголовке
  группы
- **Переименовать, сменить иконку, переупорядочить закладки** — всё в диалоге
  редактирования группы

### Управление закладками

- **Добавить по URL** — в диалоге редактирования группы вставьте ссылку;
  название и favicon загрузятся автоматически
- **Переместить закладку** — перетащите за ручку, появляющуюся при наведении,
  внутри группы или в другую группу
- **Изменить / удалить** — кнопки в диалоге редактирования группы

### Бэкапы

Закладки хранятся в `chrome.storage.sync` и синхронизируются между устройствами
с вашим Google-аккаунтом. Для дополнительной надёжности настройте файловые
бэкапы:

1. Откройте **Настройки** (шестерёнка в шапке)
2. В разделе **Бэкап** выберите файл для **мгновенного** бэкапа (при каждом
   изменении) и/или **ежедневного**
3. Укажите папку, синхронизируемую с облаком (Dropbox, Google Drive и т.д.), для
   копий вне компьютера

Красная точка на иконке настроек означает, что файл бэкапа не выбран.

### Импорт / Экспорт

В **Настройках** можно экспортировать закладки в JSON и импортировать из JSON
или HTML-экспорта закладок Chrome. Импорт заменяет все текущие закладки
(потребуется подтверждение).
